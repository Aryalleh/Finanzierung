# 💶 Finanzierung — مدیریت حقوق ماهانه

یک **PWA** (وب‌اپلیکیشن نصب‌شدنی) روی **Cloudflare Workers** برای مدیریت مالی ماهانه به روش «پاکت‌بندی» (Envelope Budgeting).

هر بخش از بودجه یک **پاکت** جداگانه است و برای هر پاکت این‌ها را می‌بینید:

- **ورودی این ماه** — چقدر پول وارد این پاکت شده
- **خروجی این ماه** — چقدر از این پاکت خرج شده
- **موجودی فعلی** — مانده‌ی واقعی پاکت (مجموع ورودی‌ها منهای خروجی‌ها در همه‌ی ماه‌ها)

## پاکت‌های پیش‌فرض (درصد پیشنهادی)

| بخش | درصد پیشنهادی |
| --- | --- |
| 🏠 اجاره و هزینه‌های ثابت | ۳۵–۴۵٪ |
| 🛒 غذا و خرید روزمره | ۱۰–۱۵٪ |
| 🚆 حمل‌ونقل | ۵–۱۰٪ |
| 📱 قبض و اشتراک‌ها | ۵٪ |
| 🎉 تفریح و خرید شخصی | ۱۰٪ |
| 💰 پس‌انداز اضطراری | ۱۰–۱۵٪ |
| 📈 سرمایه‌گذاری / پس‌انداز هدفمند | ۵–۱۰٪ |

پاکت‌ها قابل ویرایش، اضافه‌شدن و حذف‌اند.

## امکانات

- 💸 **تقسیم حقوق**: مبلغ کل حقوق را وارد کنید تا به‌صورت خودکار بر اساس درصد هر پاکت تقسیم و ثبت شود (درصدها قابل تنظیم‌اند).
- ➕➖ ثبت سریع ورودی/خروجی برای هر پاکت.
- 📅 فیلتر بر اساس ماه.
- 💱 انتخاب واحد پول (یورو، دلار، لیر، ریال، تومان).
- 📱 نصب‌شدنی روی موبایل و دسکتاپ + کار در حالت آفلاین (پوسته‌ی برنامه کش می‌شود).
- 🌗 پشتیبانی از حالت تیره و راست‌به‌چپ (RTL).

## معماری

```
├── src/worker.js            ← Cloudflare Worker: API + سرو فایل‌های ثابت
├── public/                  ← رابط کاربری PWA (استاتیک)
│   ├── index.html
│   ├── app.js
│   ├── styles.css
│   ├── manifest.webmanifest
│   ├── sw.js                ← Service Worker (آفلاین)
│   └── icons/
├── migrations/0001_init.sql ← طرح پایگاه‌داده و پاکت‌های پیش‌فرض
└── wrangler.toml            ← پیکربندی Cloudflare
```

داده‌ها در **Cloudflare D1** (پایگاه‌داده SQLite) ذخیره می‌شوند. Worker در اولین درخواست، جدول‌ها را در صورت نبود می‌سازد و پاکت‌های پیش‌فرض را درج می‌کند.

## راه‌اندازی و انتشار

پیش‌نیاز: حساب Cloudflare و [Node.js](https://nodejs.org).

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) ورود به حساب Cloudflare
npx wrangler login

# ۳) ساخت پایگاه‌داده D1
npm run db:create
#    خروجی یک database_id می‌دهد؛ آن را در wrangler.toml جایگزین REPLACE_WITH_YOUR_DATABASE_ID کنید.

# ۴) ساخت جدول‌ها و درج پاکت‌های پیش‌فرض
npm run db:init

# ۵) انتشار
npm run deploy
```

پس از انتشار، آدرس `*.workers.dev` به شما داده می‌شود؛ آن را در مرورگر باز کنید و از منوی مرورگر گزینه‌ی «نصب برنامه / Add to Home Screen» را بزنید.

## اجرای محلی (برای توسعه)

```bash
npm install
npm run db:init:local   # ساخت جدول‌ها در پایگاه‌داده‌ی محلی
npm run dev             # اجرای محلی روی http://localhost:8787
```

## API

| متد | مسیر | توضیح |
| --- | --- | --- |
| `GET` | `/api/pockets?month=YYYY-MM` | فهرست پاکت‌ها با ورودی/خروجی ماه و موجودی کل |
| `POST` | `/api/pockets` | ساخت پاکت |
| `PUT` | `/api/pockets/:id` | ویرایش پاکت |
| `DELETE` | `/api/pockets/:id` | حذف پاکت |
| `GET` | `/api/summary?month=YYYY-MM` | جمع کل ورودی/خروجی/موجودی |
| `GET` | `/api/transactions?month=&pocket_id=&limit=` | فهرست تراکنش‌ها |
| `POST` | `/api/transactions` | ثبت تراکنش (`type`: `income` یا `expense`) |
| `DELETE` | `/api/transactions/:id` | حذف تراکنش |
| `POST` | `/api/distribute` | تقسیم حقوق بین پاکت‌ها |

نمونه‌ی تقسیم حقوق:

```json
POST /api/distribute
{
  "amount": 2500,
  "occurred_on": "2026-09-01",
  "allocations": [
    { "pocket_id": 1, "percent": 40 },
    { "pocket_id": 2, "percent": 12 }
  ]
}
```

اگر `allocations` ارسال نشود، از نقطه‌ی میانی بازه‌ی درصد هر پاکت استفاده و نسبت به مجموع نرمال‌سازی می‌شود.
